# Vedic Verse

A premium way to speak with the Bhagavad Gita — liquid glass over OLED black, one terracotta ember, serif for scripture.

**Run it:** open `index.html` in any modern browser, or visit the GitHub Pages site. First launch downloads the open-licensed Gita corpus (700 verses — Devanagari, IAST, English, Hindi) and caches it for offline use.

**Conversation engines:** a grounded offline voice works with no setup; paste an Anthropic or Gemini key in Profile → Intelligence for live conversation (keys stay in your browser). Gemini keys also enable generated Darshan imagery.

Full docs in this repo's README sections: features, security audit, licensing notes, and the Expo port path.
